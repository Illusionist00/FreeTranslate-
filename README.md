# FreeTranslate 免费双语翻译

开源免费的 Chrome 网页双语翻译扩展。无需登录、无会员、无配额、无需 API Key。

## 功能

- **整页双语对照翻译**：双语 / 仅译文 / 原文三种模式，译文根据元素类型智能定位（短交互元素右侧同行、长文本正下方）
- **实时检测翻译**：滚动加载 / 无限流 / Shadow DOM / 原地文本变更均自动翻译
- **悬停翻译**：Ctrl+悬停查词（按键可配置）
- **划词翻译**：选中文字弹出"译"按钮
- **输入框翻译**：连续按 3 次空格
- **YouTube 双语字幕**：旁路抓取 timedtext 字幕轨 → 整轨预翻译 → 按播放时间轴即时显示自绘译文层（零请求延迟、可调位置/字号），DOM 观察兜底
- **播放器内嵌设置**：控制栏"译"按钮 + 设置面板（开关/译文位置/译文字号）
- **悬浮球**：点击翻译/恢复；悬停弹出"控制面板"；面板内含显示模式、目标语言、功能开关
- **站点规则**：始终翻译 / 永不翻译（支持 * 通配）
- **快捷键**：Alt+A 翻译、Alt+W 模式切换、Alt+I 输入框翻译
- **翻译引擎**：Google 免费端点（批量翻译）+ Bing 免费端点兜底，LRU 缓存

## 安装（开发模式）

1. 下载本仓库代码
2. Chrome 打开 `chrome://extensions`
3. 右上角开启「开发者模式」
4. 点「加载已解压的扩展程序」，选择本目录

## 项目结构

```
manifest.json          # 扩展清单（版本号在此递增）
background.js          # 翻译引擎（Google/Bing 批量）、缓存、消息路由
content/main.js        # 整页翻译管道、动态检测、悬浮球、控制面板
content/tools.js       # 悬停 / 划词 / 输入框翻译
content/subtitles.js   # YouTube 双语字幕
content/styles.css     # 注入样式
popup/                 # 工具栏弹窗
options/               # 完整设置页
icons/                 # 图标
```
